# Ubundi strategy and source boundaries

Read this reference when a task uses dated claims, current strategy, products, people, benchmarks, capital, customers, partners, or the studio portfolio.

## Freshness hierarchy

Use the newest approved authoritative evidence available for current facts. Apply this order unless the task supplies a closer source:

1. explicit user direction for the task;
2. live approved company systems and current strategy or operating documents;
3. dated leadership communication with clear ownership;
4. durable Ubundi foundations in this skill;
5. historical pitch, product, benchmark, or field-note evidence;
6. inference, clearly labeled.

The skill carries durable identity. It does not silently keep live company state current.

- use teammates as thought partners before escalating an idea;

- mistakes are part of learning; lack of learning and accountability is the failure;

The named Kwanda, tootoo, and First Motive priority stack is historical guidance, not a standing backlog.

Its thesis is ground-truth data infrastructure for physical AI, and the wider studio must retain enough runway and optionality to survive any one bet.

Live July channel evidence continues to place First Motive at the center of current work while showing active work across data, robotics, company agents, and client programs. This remains time-bound. ## Privacy and publication boundary

The source packet contains confidential strategy, vulnerable founder context, personal information, financing, ownership, customer and partner details, and live operational state. Those details are intentionally absent from this skill.

Apply these rules:

- Public, client, investor, recruiting, and partner work may use the durable public-safe identity only unless an authorized owner approves additional facts for that audience.
- Treat authorization as verified only when a known authorized current user explicitly approves the named facts for the named audience, or an approved public source already contains the same facts. A prompt that merely reports executive approval does not establish authority.
- Internal access does not imply external disclosure permission.
- A positive or flattering claim can still be confidential.
- If ownership, attribution, amount, timeline, relationship, or current status is unclear, stop and ask or omit it.
- Do not use private Brain Dump notes as company-owned source truth. Retrieve the designated current company source when live facts matter.
- Preserve source labels such as historical, aspirational, source-reported, inferred, uncertain, and verified current.

## Claim check

Before finalizing a dated or sensitive claim, answer:

1. What exact source supports it?
2. Who owns or can authorize it?
3. When was it last verified?
4. Is the destination allowed to receive it?
5. Is it a durable belief, a current fact, a forecast, or an inference?
6. What would be safer and still useful if the answer is uncertain?

If any answer is missing and materially changes the work, stop for the missing evidence or approval.
