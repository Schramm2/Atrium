# FM Design

For First Motive visual work, load [`references/DESIGN.md`](references/DESIGN.md)
and follow it as the shared design system.

Use it for:

- colour tokens and palette choices
- typography, scale, spacing, and layout rhythm
- elevation, surfaces, and component recipes
- accessibility and WCAG contrast checks
- the First Motive do's and don'ts

Treat the vendored design doc here as the single fm-ai copy of the canonical
`DESIGN.md` from the First Motive web repo. If it diverges from the canonical
copy, update the canonical file first and re-vendor this reference instead of
forking the design system here.
